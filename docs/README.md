# Mapa de execução do roteiro

O roteiro local tem 13 páginas chamadas etapas. As pastas de documentação agrupam incrementos de trabalho; não renumeram as páginas do PDF. A base metodológica permanece a pasta `contexto para IA`.

| Página do roteiro | Entrega neste repositório |
| --- | --- |
| 1 — entrega e recorte | README raiz e cinco RF na especificação |
| 2 — fluxo dos requisitos | CT-FL01, features e contrato OpenAPI |
| 3 — engenharia reversa | [Etapa 1](etapa-1/README.md), diagnóstico, RN e decisões |
| 4 — regras e decisões | [Etapa 2](etapa-2/README.md), decisões de evolução documentadas |
| 5 — BDD | Features e steps Cucumber por HTTP real |
| 6 — cliente/servidor | [Etapa 3](etapa-3/README.md), serviços/API; [etapa 4](etapa-4/README.md), frontend |
| 7 — contrato | [api.yaml](api.yaml) e testes de entrada/status/estado |
| 8 — ferramentas | Maven Wrapper, JDK 21, versões fixas, lockfile, Jupiter/Vintage/Cucumber |
| 9 — incremental e comparação | TDD, regressão e ComparacaoLegadoTest |
| 10 — fluxo principal | Cucumber e Cypress CT-FL01; fixture apenas no processo de testes |
| 11 — qualidade | [Etapa 5](etapa-5/README.md), JaCoCo/PIT e evidências |
| 12 — GitHub e apresentação | [Etapa 6](etapa-6/README.md), CI, entrega e [apresentação](apresentacao.md) |
| 13 — autoria e IA | [USO_DE_IA.md](../USO_DE_IA.md) e [contribuições](contribuicoes.md) |

As execuções reais estão em [evidencias/entrega](../evidencias/entrega/README.md). Revisão pelos alunos, identificação de autores e apresentação ao professor são atividades humanas ainda a realizar. Não se confundem com testes automatizados aprovados.

O [registro de fontes](etapa-1/fontes-e-rastreabilidade.md) identifica os trechos locais consultados. Documentação oficial das ferramentas foi usada para configurar o que o roteiro prevê; não substituiu as fontes locais na definição do processo.
